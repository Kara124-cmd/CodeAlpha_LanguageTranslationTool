
# Language Translation Tool
One line: what this app does.

## Features
- Translate text between English, Urdu, and Hindi
- Copy the translation with one click
- Listen to the translation (text-to-speech)

## Tools Used
Python, Streamlit, Requests, MyMemory Translation API, gTTS

## How to Run
pip install -r requirements.txt
streamlit run app.py

## Example
Input: I am learning Artificial Intelligence (English to Urdu)
Output: میں مصنوعی ذہانت سیکھ رہا ہوں
